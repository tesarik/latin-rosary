# English texts still to be sourced

Work in progress from the cs/en rework (see `CHANGELOG.md` → *Unreleased*).

`PRAYERS_EN` in `src/rosary/prayers.ts` is complete and shipping. The banner
above the table records which texts were checked against which witness.

When a text below is settled, move its row out of this file and update the
banner in `prayers.ts`.

## Optional — a printed source for the Litany of the Saints

`LITANY_SAINTS_VERSICLES` and `LITANY_SAINTS_COLLECTS` follow the traditional
text at salvemariaregina.info, which names no printed source. A photo of the
same section from a pre-1962 English hand missal (St. Andrew, Saint Joseph,
Lasance) would let the banner cite a book.

## Deliberately not on this list

`BRIGIT_*`: there is no authoritative Latin or Czech either, so the English is a
translation of our own text. There is nothing to verify it against.
